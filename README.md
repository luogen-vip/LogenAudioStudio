# 罗根音频工作室 · Logen Audio Studio

作者：**罗根**（GitHub: [luogen-vip](https://github.com/luogen-vip)）

一个真正能用的安卓音频精修工具：导入音频 → 看波形 → 选段调音 → 裁剪 → 混音合成 → 导出真 MP3 / WAV。

## 功能

- **多工程并行**：每次导入生成一个工程，全部保存在应用私有目录，清后台、杀进程、重启 APP 都不会丢
- **两种导入模式**
  - 导入整首歌（单轨）
  - 导入人声 + 伴奏两条，分别精修后合成一首
- **波形可视化**：按真实峰值绘制，全曲任何位置可点可拖
- **区间编辑**：在波形上框选任意一段，单独加/减增益，段落标签随时删除
- **整轨调音**
  - 音量增益 −24 ~ +24 dB
  - 低切 0 ~ 400 Hz（去浑浊）
  - 低频厚度 / 高频亮度 ±12 dB
  - 混响 0 ~ 100%
  - 变调 −12 ~ +12 半音（旋律升降，速度不变）
  - 速度 0.5 ~ 2.0x
  - 压缩 / 限幅（防爆音，出「发行质感」）
- **裁剪**：选区直接设为裁剪范围，边选边试听，导出按裁剪范围走
- **实时试听**：按当前参数真实渲染成临时音频再播放，听到的就是导出后的效果
- **混音合成**：多轨各自套自己的参数，再 `amix` 合成，音量不被自动压低
- **真实导出**
  - WAV：PCM 16bit，采样率 44100 / 48000，单/双声道
  - MP3：LAME 编码，128 / 192 / 256 / 320 kbps
  - 不是改后缀，参数真实写进文件
- **默认存到** `/storage/emulated/0/Download/LogenAudioStudio`（拿到「所有文件访问」权限后直接写公共下载目录）
- **恢复默认**：一键把所有参数还原成原始音频状态
- **分离成人声 + 伴奏（快速）**：立体声歌曲按中置声道提取人声，再用反相抵消做伴奏；分离后两条轨道各自独立编辑，最后混音合成

## 技术栈

- Flutter UI（波形、时间轴拖拽、工程管理）
- FFmpeg Kit（解码、滤波、混音、编码；滤镜链真实执行）
- 工程数据以 JSON 落盘，音频副本单独存储，重启自动恢复

## 编译

GitHub Actions 云编译，push 到 `main` 即出 APK：

```
flutter build apk --release
```

签名配置在 `android/app/build.gradle.kts`，keystore 为 `android/app/upload-keystore.jks`。
